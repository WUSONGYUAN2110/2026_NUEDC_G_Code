# AX7020 开发板 IO 与外设连接

## 使用规则

- PS 外设使用 Zynq Processing System 的 MIO 配置，不在 XDC 中约束封装管脚。
- Bank 13、34、35 的用户 PL IO 供电均为 3.3 V；普通单端 IO 使用 `LVCMOS33`。
- HDMI 的三组差分数据和差分时钟使用 `TMDS_33`；DDC、CEC、HPD、输出使能等单端信号使用 `LVCMOS33`。
- `IO1_nP/N`、`IO2_nP/N` 是扩展口网络名称，不能仅按 `P/N` 命名假定为差分接口或直接套用差分 IO 标准。
- 板载 RTC 为 DS1302 三线串行器件（`SCLK`、双向 `DATA`、`RESET`），不是 I2C；不要将其接入 I2C 控制器或沿用 EEPROM 的时序。
- 按键均有上拉、按下接地，为低电平有效；板载 PL/PS LED 均由 FPGA/PS 下拉点亮，为低电平有效。
- 同一封装管脚只可选择其实际连接的一个板载功能；不要把 HDMI、RTC、EEPROM、LED/KEY 等专用 IO 同时复用于扩展接口。

## 板级基础参数

| 项目 | AX7020 参数 |
| --- | --- |
| FPGA | 实物 `XC7Z020CLG400ABX1613D5216336A`；Vivado 器件名 `xc7z020clg400-2` |
| PS 参考时钟 | 33.333333 MHz |
| PL 有源时钟 | `PL_GCLK`，`U18`，50 MHz（20 ns） |
| PS DDR3 | 实物丝印 `H5TQ4G63CFRROC` × 2，`256M × 16 bit` × 2，合并为 32-bit 总线，总计 1 GiB；Vivado 使用兼容的 `MT41J256M16 RE-125` 预设，533.333 MHz |
| QSPI Flash | `W25Q256`，32 MiB，x4 single-SS |

## PS MIO

### 默认流程可选外设

| 外设 | 信号 | MIO 映射 | 说明 |
| --- | --- | --- | --- |
| QSPI Flash | `CS#` / `SCK` | MIO1 / MIO6 | x4 single-SS；用于 QSPI 启动 |
| QSPI Flash | `D[3:0]` | `D0→MIO2`，`D1→MIO3`，`D2→MIO4`，`D3→MIO5` | W25Q256 |
| PS UART1（模板默认） | `TX` / `RX` | MIO8 / MIO9 | 引至 MIO 扩展连接器；Bank 0 为 3.3 V，只连接 3.3 V TTL 串口，TX/RX 交叉并共地，不可直接连接 RS-232 电平 |
| PS UART1（可选板载串口） | `TX` / `RX` | MIO48 / MIO49 | 经 CP2102 的板载 USB 调试串口；与 MIO8/9 映射二选一 |
| SD0 | `CLK` / `CMD` | MIO40 / MIO41 | Micro SD |
| SD0 | `D[3:0]` | `D0→MIO42`，`D1→MIO43`，`D2→MIO44`，`D3→MIO45` | 4-bit 数据总线 |
| SD0 | `CD` | MIO47 | 卡检测 |
| PS GPIO | PS LED 1 / 2 | MIO0 / MIO13 | 低电平点亮 |
| PS GPIO | PS KEY 1 / 2 | MIO50 / MIO51 | 低电平有效 |

### 其他已连接 PS 外设

| 外设 | MIO 映射 | 说明 |
| --- | --- | --- |
| Gigabit Ethernet 0 RGMII | MIO16-27 | 连接 RTL8211E-VL：`TXCK`、`TXD[3:0]`、`TXCTL`、`RXCK`、`RXD[3:0]`、`RXCTL` |
| Gigabit Ethernet 0 MDIO | MIO52-53 | 连接 RTL8211E-VL：`MDC`、`MDIO`；硬件默认 PHY 地址为 `001` |
| USB0 OTG | MIO28-39 | 连接 USB3320：ULPI `DATA[0:7]`、`DIR`、`STP`、`NXT`、`CLK` |
| USB0 PHY reset | MIO46 | USB3320 `OTG_RESETN` |
| MIO 扩展口 | MIO7-12、MIO14-15 | 引至 MIO 扩展连接器；配置其他功能前先确认复用 |

板载 USB JTAG 通过 FT232HL 连接 Zynq JTAG 引脚，不属于 PS MIO 或 PL XDC 约束。
